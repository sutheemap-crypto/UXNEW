                <div class="grid grid-cols-1 md:grid-cols-2 gap-4">
                    <!-- Rule 1 -->
                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">1</span>
                            <h3 class="font-bold text-slate-800">Strive for Consistency (สร้างความสม่ำเสมอ)</h3>
                        </div>
                        <p class="text-sm text-slate-600">รักษาความสม่ำเสมอในโทนสี เลย์เอาต์ สัญลักษณ์ และคำศัพท์[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span) การออกแบบที่สม่ำเสมอช่วยลดระยะเวลาเรียนรู้ (Learning Curve) ทำให้ผู้ใช้คาดเดาการทำงานได้ง่ายขึ้น[span_4](start_span)[span_4](end_span) เช่น การใช้ Component-Driven และ Design Tokens มาตรฐาน[span_5](start_span)[span_5](end_span)</p>
                    </div>

                    <!-- Rule 2 -->
                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">2</span>
                            <h3 class="font-bold text-slate-800">Seek Universal Usability / Enable Shortcuts (รองรับผู้ใช้ทุกระดับ)</h3>
                        </div>
                        <p class="text-sm text-slate-600">ออกแบบระบบยืดหยุ่น โดยมือใหม่ (Novice) ต้องการ Tooltips และการนำทางแบบ Step-by-step[span_6](start_span)[span_6](end_span) ขณะที่ผู้ใช้ระดับสูง (Expert/Power Users) ต้องการคีย์ลัด (Shortcuts) เพื่อข้ามขั้นตอน[span_7](start_span)[span_7](end_span) รวมถึงคำนึงถึงผู้พิการทางสายตาผ่าน VoiceOver[span_8](start_span)[span_8](end_span)</p>
                    </div>

                    <!-- Rule 3 -->
                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">3</span>
                            <h3 class="font-bold text-slate-800">Offer Informative Feedback (ตอบสนองที่ให้ข้อมูลเสมอ)</h3>
                        </div>
                        <p class="text-sm text-slate-600">ทุกการกระทำของผู้ใช้ (Input) ระบบต้องตอบสนองทันที (Output)[span_9](start_span)[span_9](end_span) สำหรับงานขนาดเล็กให้ใช้ Micro-actions เช่น การเปลี่ยนสีไอคอน[span_10](start_span)[span_10](end_span) งานขนาดใหญ่ให้ใช้ Progress Bar บอกสถานะ[span_11](start_span)[span_11](end_span)</p>
                    </div>

                    <!-- Rule 4 -->
                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">4</span>
                            <h3 class="font-bold text-slate-800">Design Dialog to Yield Closure (ออกแบบให้มีจุดจบชัดเจน)</h3>
                        </div>
                        <p class="text-sm text-slate-600">กระบวนการทำงานต้องมีจุดเริ่มต้น ดำเนินการ และจุดจบสมบูรณ์[span_12](start_span)[span_12](end_span) การขึ้นข้อความเช่น "Installation Complete" หรือ "Thank You" ช่วยลดความกังวลใจของผู้ใช้[span_13](start_span)[span_13](end_span)</p>
                    </div>

                    <!-- Rule 5 -->
                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">5</span>
                            <h3 class="font-bold text-slate-800">Offer Simple Error Handling (ป้องกันและจัดการข้อผิดพลาด)</h3>
                        </div>
                        <p class="text-sm text-slate-600">หลีกเลี่ยงการลงโทษผู้ใช้ด้วยรหัส Error ทางเทคนิค (System-Centric)[span_14](start_span)[span_14](end_span)[span_15](start_span)[span_15](end_span) แต่ต้องตรวจจับข้อมูลแบบ Real-time และบอกวิธีแก้ไขด้วยภาษาคน (User-Centric)[span_16](start_span)[span_16](end_span)[span_17](start_span)[span_17](end_span)</p>
                    </div>

                    <!-- Rule 6 -->
                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">6</span>
                            <h3 class="font-bold text-slate-800">Permit Easy Reversal of Actions (อนุญาตให้ย้อนกลับได้ง่าย)</h3>
                        </div>
                        <p class="text-sm text-slate-600">สร้างตาข่ายรองรับความปลอดภัย (Safety Net) เช่น ปุ่ม Undo/Redo, Cancel หรือ Back เพื่อให้ผู้ใช้กล้าทดลองใช้งานโดยไม่กลัวระบบพัง[span_18](start_span)[span_18](end_span)</p>
                    </div>

                    <!-- Rule 7 -->
                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">7</span>
                            <h3 class="font-bold text-slate-800">Support Internal Locus of Control (ผู้ใช้เป็นผู้ควบคุม)</h3>
                        </div>
                        <p class="text-sm text-slate-600">ทำให้ผู้ใช้รู้สึกว่าตนเป็นผู้กุมบังเหียนและริเริ่มกระบวนการ (User-Initiated) สามารถยกเลิกการทำงานหรือ Force Quit ได้ตลอดเวลา[span_19](start_span)[span_19](end_span)</p>
                    </div>

                    <div class="bg-slate-50 p-4 rounded-xl border border-slate-200 hover:shadow-md transition">
                        <div class="flex items-center gap-2 mb-2">
                            <span class="bg-blue-600 text-white w-7 h-7 rounded-full flex items-center justify-center font-bold text-sm">8</span>
                            <h3 class="font-bold text-slate-800">Reduce Short-Term Memory Load (ลดภาระหน่วยความจำ)</h3>
                        </div>
                        <p class="text-sm text-slate-600">สมองมนุษย์จำข้อมูลระยะสั้นได้จำกัดเพียง 5±2 รายการ[span_20](start_span)[span_20](end_span) ควรใช้หลัก Recognition over Recall เช่น ตัวเลือก Autofill หรือ Dropdown แทนการให้นึกจำเอง[span_21](start_span)[span_21](end_span)</p>
                    </div>

    <script>
        function switchTab(tabId) {
            // Hide all tab content
            document.querySelectorAll('.tab-content').forEach(content => {
                content.classList.add('hidden');
                content.classList.remove('block');
            });

            // Reset tab styles
            document.querySelectorAll('.tab-btn').forEach(btn => {
                btn.classList.remove('tab-active', 'text-white');
                btn.classList.add('text-white/80');
            });

            // Show selected tab content
            document.getElementById('content-' + tabId).classList.remove('hidden');
            document.getElementById('content-' + tabId).classList.add('block');

            // Set active button style
            const activeBtn = document.getElementById('tab-' + tabId);
            activeBtn.classList.add('tab-active', 'text-white');
            activeBtn.classList.remove('text-white/80');
        }

        function toggleAnswer(ansId) {
            const ans = document.getElementById(ansId);
            ans.classList.toggle('hidden');
        }
    </script>
